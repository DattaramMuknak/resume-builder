# Resume Builder

A full-stack web application for creating, editing, and managing professional resumes.

## Tech Stack

- Frontend: React.js, Vite
- Backend: Spring Boot, Java
- Database: MongoDB
- Authentication: JWT
- Payment: Razorpay
- Cloud Storage: Cloudinary

## Features

- User registration and login
- Create and edit resumes
- Multiple resume templates
- Profile photo upload
- Resume PDF generation
- Resume sharing via email
- Online payment integration

## Project Structure

resume-builder/       # React Frontend
resumebuilderapi/     # Spring Boot Backend

## Run Locally
- Frontend
cd resume-builder
npm install
npm run dev
- Backend
cd resumebuilderapi
./mvnw spring-boot:run
